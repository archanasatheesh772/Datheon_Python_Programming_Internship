# Datheon Python Programming Internship

This repository contains Python projects completed as part of the Datheon Python Programming Internship.

## Projects

### Task 1: Hangman Game
A word-guessing game where users guess letters to find a randomly selected word within a limited number of attempts.

**File:** `Hangman-Game/hangman.py`

**Run:**
```bash
python hangman.py
```

### Task 2: Investment Portfolio Tracker
A Python application that calculates investment value, profit or loss, and percentage returns. It saves portfolio summaries in a CSV file.

**File:** `Investment-Portfolio-Tracker/portfolio.py`

**Run:**
```bash
python portfolio.py
```

### Task 3: Automatic File Organizer
A Python utility that organizes files into folders based on their file extensions.

**File:** `File-Organizer/organizer.py`

**Run:**
```bash
python organizer.py
```

### Task 4: Customer Support Chatbot
A rule-based chatbot that recognizes greetings, answers frequently asked questions, handles multiple intents, and responds to unrecognized queries.

**Files:**
- `Customer-Support-Chatbot/chatbot.py`
- `Customer-Support-Chatbot/sample_faq.json`

**Run:**
```bash
python chatbot.py
```

## Technologies Used
- Python 3
- JSON
- Regular Expressions
- OS and Shutil modules
- Pathlib
- CSV

## How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Open the required project folder in the terminal.
4. Run the corresponding Python file using `python filename.py`.
